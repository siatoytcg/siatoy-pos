# Siatoy TCG · POS

ระบบขายหน้าร้านและจัดการสต๊อกสำหรับร้านการ์ดสะสมเสี่ยทอย TCG
ยกมาจากเดโม `reference/Siatoy-TCG-POS-Demo.html` (ไฟล์เดียว ข้อมูลไม่ถูกบันทึก)
ให้กลายเป็นระบบใช้จริงที่หน้าร้านกับบูธงานใช้พร้อมกันได้ และขายต่อได้ตอนเน็ตหลุด

## โครงที่เลือกใช้

| ส่วน | เลือกใช้ | เหตุผล |
|---|---|---|
| หน้าเว็บ | HTML + ES module ล้วน **ไม่มีขั้นตอน build** | ต่อยอดจากโค้ดเดโมได้ตรง ๆ ไม่ต้องลง node_modules หลายหมื่นไฟล์ในโฟลเดอร์ที่ซิงก์ OneDrive อยู่ |
| ไลบรารีภายนอก | วางไว้ใน `public/vendor/` เป็นไฟล์ในโปรเจกต์ | ตอนออฟไลน์ต้องไม่มีอะไรต้องโหลดจากเน็ต |
| ฐานข้อมูล | Supabase (PostgreSQL + Auth + Storage) | ฟรีในช่วงเริ่ม มีระบบสิทธิ์ระดับแถวในตัว |
| ข้อมูลในเครื่อง | IndexedDB | เก็บสินค้า ราคา และคิวบิลที่ยังส่งไม่สำเร็จ |
| โฮสต์ | หน้าเว็บเป็นไฟล์นิ่ง วางที่ไหนก็ได้ | ไม่มี build ก็ไม่มีอะไรพัง |

## โครงโฟลเดอร์

```
db/         migration ของฐานข้อมูล  รันตามลำดับเลข
src/        โค้ดแอป  (pages = หน้าจอ, lib = ตรรกะ, ui = ส่วนประกอบร่วม)
public/     ไฟล์นิ่ง  โลโก้ ฟอนต์ ไลบรารี
docs/       บันทึกการตัดสินใจ
reference/  เดโมตั้งต้นและโลโก้  ไว้เทียบ ไม่ใช่โค้ดที่รัน
```

## รัน migration

เปิด Supabase → SQL Editor → วางเนื้อไฟล์ `db/001_schema.sql` แล้วกด Run
(หรือถ้าติดตั้ง Supabase CLI แล้วใช้ `supabase db push`)

สคีมาถูกทดสอบกับ PostgreSQL 16 จริงแล้ว ทั้งกรณีบิลซ้ำจากเครื่องออฟไลน์
การยกเลิกบิลแล้วคืนของ และการกันแก้สมุดเดินของย้อนหลัง

## กติกาที่ห้ามพัง

1. **สต๊อกอ่านจาก `stock_moves` เท่านั้น** ห้ามมีช่อง "คงเหลือ" ที่เขียนทับได้
2. **บิลเก็บราคาและต้นทุน ณ วันขาย** ไว้ในบรรทัดบิล ห้ามคำนวณย้อนหลังจากราคาปัจจุบัน
3. **ต้นทุนอยู่ใน `product_costs` / `sale_item_costs`** ซึ่ง RLS ปิดไม่ให้พนักงานอ่าน
   ห้ามย้ายกลับไปไว้ในตารางเดียวกับสินค้า
4. **รหัสบิลและ id สร้างจากเครื่องขาย** ส่งขึ้นเซิร์ฟเวอร์ด้วย `on conflict do nothing` เสมอ

## เปิดใช้งาน

หน้าเว็บเป็นไฟล์นิ่งล้วน วางที่ไหนก็เปิดได้ ตอนนี้ตั้ง GitHub Pages ไว้ที่ branch `master` โฟลเดอร์ราก
เมื่อ push ขึ้นไปแล้วจะเปิดได้ที่ `https://nalatikana.github.io/siatoy-pos/`

เปิดในเครื่องเพื่อพัฒนา (ต้องเปิดผ่าน http ไม่ใช่ดับเบิลคลิกไฟล์ เพราะใช้ ES module)

```
python -m http.server 8000
```

แล้วเปิด http://localhost:8000

### สถานะตอนนี้

ทำครบทั้ง 13 หน้าแล้ว ทุกหน้าทำงานกับข้อมูลจริงในเครื่อง ไม่มีหน้าไหนเป็นตัวอย่างค้างไว้

| หน้า | ทำอะไรได้ |
|---|---|
| ขายสินค้า | ยิงบาร์โค้ด กรองหมวด ส่วนลดรายชิ้นพร้อมเหตุผล ส่วนลดท้ายบิลบาท/% ค่าธรรมเนียมบัตร ระบุสมาชิก เปิดการ์ด (เจ้าของเท่านั้น) |
| บิลขาย / ยกเลิก | กรองช่วงวัน เปิดดูรายการในบิล ยกเลิกทั้งใบแล้วของกลับเข้าคลังจริง พนักงานยกเลิกเองไม่ได้ |
| รับเข้า / ตัดออก | รับเข้าพร้อมผู้ฝากขายและเลข PO · ตัดออกพร้อมเหตุผล · ยกไปบูธเป็นการย้ายจุดขายสองบรรทัด · ประวัติจริง |
| สินค้า & สต๊อก | ค้นหา กรองหมวด แยกยอดรายจุดขายกับยอดรวม เพิ่ม/แก้สินค้า ต้นทุนเบลอสำหรับพนักงาน |
| นำเข้าข้อมูลสินค้า | อ่านไฟล์ CSV หรือวางจาก Excel · เดาคอลัมน์ให้ · ตรวจข้อมูลก่อนนำเข้า · ลงยอดยกมาเข้าสมุดเดินของ · นำเข้าซ้ำได้โดยไม่เกิดของซ้ำ |
| พิมพ์บาร์โค้ด | CODE128 ปัดความกว้างแท่งให้ลงตัวกับจุดเครื่องพิมพ์ตาม dpi ที่ตั้งไว้ คิวพิมพ์จัดลำดับได้ |
| บล็อกเซต & ราคา | ปรับราคาทั้งเซตพร้อมเก็บประวัติราคาเดิมและเหตุผล |
| ผู้ฝากขาย | ยอดขายรายเจ้าจากบิลจริง ค่าคอมมิชชัน ยอดต้องจ่ายคืน สรุปรอบจ่าย |
| สต๊อกออกงาน | เทียบยอดหน้าร้านกับบูธ ดูของที่บูธว่ายกไปเท่าไหร่ขายไปเท่าไหร่ และรับกลับเข้าคลัง |
| กระทบยอดธนาคาร | นำเข้า CSV จากแอปธนาคาร (รองรับ พ.ศ. และตัวเลขมีลูกน้ำ) จับคู่บิลอัตโนมัติ คัดเฉพาะรายการที่ต้องตรวจ |
| สมาชิก & แต้ม | เพิ่มสมาชิก ดูประวัติการซื้อรายคน |
| รายงานสรุป | ยอดขาย ส่วนลด กำไรขั้นต้นจากต้นทุนในบิล แยกช่องทางจ่าย สินค้าขายดี |
| แจ้งเตือน | ประกอบข้อความสรุปจากข้อมูลจริง ส่งเข้า Telegram ได้เลย · LINE ต้องรอเซิร์ฟเวอร์ |
| ตั้งค่าระบบ | จุดขายของเครื่อง ความละเอียดเครื่องพิมพ์ ค่าธรรมเนียมบัตร อัตราแต้ม เพิ่มบูธงาน ล้างข้อมูลทดลอง |

ยังไม่ได้ต่อฐานข้อมูลกลาง แถบบนขวาจึงขึ้นว่า **โหมดทดลอง** ข้อมูลทั้งหมดอยู่ใน IndexedDB
ของเบราว์เซอร์เครื่องนั้นเท่านั้น ยังไม่แชร์ข้ามเครื่อง สินค้าตั้งต้นเป็นชุดเดียวกับเดโม
(ลองพิมพ์ `8859002` ในช่องยิงบาร์โค้ด)

ต่อไป : ต่อ Supabase (รอ URL + anon key) แล้วทำระบบล็อกอิน การซิงก์ขึ้นเซิร์ฟเวอร์
และงานตั้งเวลาส่งสรุปประจำวัน

## เครื่องพิมพ์ร้าน 3 ช่อง

เพิ่มโหมด **เครื่องร้าน · 3 ช่อง** ในหน้าพิมพ์บาร์โค้ด ใช้โปรไฟล์ 32 × 25 มม. ที่ปรับกับ 4BARCODE 4B-2054B แล้ว เปิด `tools/printer/Start-Printer.cmd` บน Windows ก่อนใช้งาน ดู [คู่มือเชื่อมเครื่องพิมพ์](docs/printer-integration.md) สำหรับการติดตั้งและข้อจำกัด
