# Siatoy Printer Helper สำหรับลูกค้า

ชุดนี้ติดตั้งตัวช่วยพิมพ์ฉลาก 32 × 25 มม. 3 ช่อง สำหรับ Windows และเครื่อง **4BARCODE 4B-2054**

## สิ่งที่ต้องเตรียม

- Windows ที่ต่อเครื่องพิมพ์ผ่าน USB
- Node.js LTS ใน PATH (ถ้าชุดติดตั้งไม่มี `runtime\node.exe`)
- ไดรเวอร์เครื่องพิมพ์จากผู้ผลิต (ไฟล์ `.inf`) และติดตั้งให้เห็นชื่อ `4BARCODE 4B-2054`

## ติดตั้ง

1. แตกโฟลเดอร์ชุดติดตั้งไว้ในเครื่องลูกค้า
2. ดับเบิลคลิก `Install-SiatoyPrinter.cmd`
3. ถ้าต้องติดตั้งไดรเวอร์พร้อมกัน ให้เปิด PowerShell แบบผู้ดูแลระบบแล้วใช้:

```powershell
./Install-SiatoyPrinter.ps1 -DriverInf 'C:\path\to\driver.inf'
```

ตัวติดตั้งจะคัดลอกไฟล์ไปที่ `%LOCALAPPDATA%\SiatoyPrinter` สร้างทางลัดใน Start Menu และเปิดตัวช่วยพิมพ์บน `127.0.0.1:18767` ให้อัตโนมัติ

แพ็กเกจนี้ไม่รวมไดรเวอร์ของผู้ผลิต เพราะไดรเวอร์ต้องตรงกับรุ่น Windows และควรแจกจ่ายตามเงื่อนไขของผู้ผลิต
